- **Posts:** Planner → Create post → tick Instagram → upload the image from `posts/` → paste the caption from the matching `.txt` → set the date and time → Schedule. Paste the alt text below too if the composer has a field for it. If it doesn't, add it in the Instagram app after the post goes live: ... → Edit → Edit alt text.
