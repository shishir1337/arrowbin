## Specs

| Type | File | Size |
|---|---|---|
| Post | PNG + caption `.txt` | 1080×1080 |
| Reel | MP4 (H.264, 30 fps, about 40 s, AI voiceover + music, no caption strip), `-cover.png`, caption `.txt` | 1080×1920 |
| Story | PNG | 1080×1920 |
| Group post | `.txt` (post text, then the first comment with the link) + PNG | 1080×1080 |

Reels and stories keep text out of the areas Facebook covers: the top 250px, the bottom 500px (reels) or 250px (stories), and the right edge of reels where the buttons sit.

## Links

- Post captions use full links tagged `utm_source=facebook&utm_medium=social&utm_campaign=social_2026_10`.
- Group post links (first comment) use `utm_medium=group`. Story link stickers use `utm_medium=story`.
- Reel captions use short plain links (`arrowbin.com/blog/...`), because links in reel captions often aren't clickable.

## Other platforms

- Instagram: use `../instagram/` (4:5 images, "link in bio" captions, alt text).
- LinkedIn: same image and caption; change `utm_source=facebook` to `utm_source=linkedin` in the link.
- X: shorten to the first paragraph plus the link.
