# Instagram

One folder per week, with the same days and topics as Facebook. Open the week's `PLAN.md` for the day-by-day list, how to post and the alt text. Nothing is scheduled yet: start once the account is recovered.

## Before the first post

1. Recover the account. Then set the name to `Arrowbin` and the username to `arrowbinhq` (see `../../ACCOUNTS-AUDIT.md`).
2. Switch to a Professional (Business) account and connect it to the Facebook page in Meta Business Suite.
3. Add two bio links:
   - Contact: `https://arrowbin.com/contact?utm_source=instagram&utm_medium=social&utm_campaign=profile`
   - Blog: `https://arrowbin.com/blog?utm_source=instagram&utm_medium=social&utm_campaign=social_2026_10`
4. Tell Claude the new handle. The website's social links still point to `instagram.com/arrowbinllc` and need updating, then a deploy and a Cloudflare purge.

## Specs and rules

- **Posts:** 1080×1350 PNG (4:5 portrait), the size Instagram's feed shows biggest. Everything important sits inside the 3:4 crop that the profile grid shows.
- **Captions:** the Facebook text, but each link line says "link in bio", because links in Instagram captions can't be clicked. 5 hashtags or fewer per post, which is Instagram's limit.
- **Alt text:** in each week's `PLAN.md`.
- **Stories:** 1080×1920 PNG, the same images as the Facebook stories. Story link stickers use `utm_source=instagram&utm_medium=story`.
- **Reels:** not part of the Instagram challenge so far. When you schedule a Facebook reel, you can tick Instagram too.
