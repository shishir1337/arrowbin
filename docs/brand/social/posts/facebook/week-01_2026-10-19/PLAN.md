## How to post (Meta Business Suite)

- **Posts:** Planner → Create post → upload the image from `posts/` → paste the caption from the matching `.txt` → set the date and time → Schedule.
- **Reels:** Create reel → upload the `.mp4` from `reels/` → paste the caption from the matching `.txt` (keep its sound-effects credit line at the end) → if it offers a thumbnail upload, use the `-cover.png` → set the date and time → Schedule. The voiceover and music are already in the video, so don't add a track. If Instagram is back, you can tick Instagram too so the reel goes out there as well.
- **Stories:** Create story → upload the image from `stories/` → set the date and time → Schedule. A story stays up for 24 hours. In the phone app you can add a Link sticker with the story's link from the table below.
- **Group posts:** post these by hand, from the group itself. Post as the Arrowbin page, paste the text from the `.txt` file in `group-posts/` and attach the image beside it if the group allows images. Then put the link from the bottom of the file in the first comment. Read each group's rules first: many ban links, or allow promotion only on set days. Use a different group each day, and don't paste the same text into several groups on the same day; Facebook can treat that as spam.
